# Still-image layers

Layer Studio combines existing still images on the CPU. It supports up to eight ordered image or adjustment layers on a canvas of at most four megapixels. It does not run an image model or require a GPU. Video layers and temporal masks are not part of this first version.

Import the original PNG, JPEG or WebP into Film media, then add it as an image layer. Film media keeps the original file bytes, including PNG transparency. The layer project binds every source and imported mask by its SHA-256 hash. Generated Aftertake stills can be imported the same way.

Image layers keep their aspect ratio and fit inside the canvas. Translation is a fraction of canvas width/height; scaling and clockwise rotation share the fixed image center. Masks attach to image pixels and follow the same transform. Transforming a layer samples premultiplied color and alpha together, directly into the bounded output canvas.

The project stores layers bottom first. Visibility, order, opacity, blend mode and transforms remain editable; changing a draft does not overwrite a completed image. A clipping switch restricts a layer to the coverage of the nearest lower unclipped image while preserving the composite's existing alpha. Hidden clipping bases hide their clipped content. This is coverage clipping, not an isolated Photoshop clipping-group implementation.

Masks can be rectangles, ellipses or separate imported images. Shape coordinates and dimensions are fractions of the source image for image layers, or of the canvas for adjustment layers. An imported mask can use its alpha or luminance multiplied by its alpha. The operations run in this order: invert, grow/shrink, feather. Growth uses a square pixel neighborhood. Disabling a mask preserves its settings and reveals the layer again. Transparent or out-of-canvas pixels do not wrap to the opposite edge.

Adjustment layers reuse the same CPU finishing implementation as Finishing Studio. They process the composite below their position in the stack, preserve its alpha and apply their mask/opacity only where intended. Spatial adjustments use alpha-weighted light spread and coverage-normalized sharpening/channel sampling, so hidden colors in transparent pixels cannot create visible fringes. Their full finishing settings, including imported curves or LUT descriptors, remain in the portable recipe even if a particular control is not shown in the layer panel. Active LUTs require the matching separately imported LUT asset.

The 27 blend modes are normal, dissolve, darken, multiply, color burn, linear burn, darker color, lighten, screen, color dodge, linear dodge, lighter color, overlay, soft light, hard light, vivid light, linear light, pin light, hard mix, difference, exclusion, subtract, divide, hue, saturation, color and luminosity. Familiar image-editor blending uses encoded sRGB values; exposure and white balance inside finishing retain their linear-light behavior. Dissolve uses a saved unsigned seed, so importing a recipe under new local asset IDs does not change its pattern. These modes are not a claim of byte-for-byte Photoshop compatibility.

Preview is a real PNG from the same compositor used for export. Save creates a durable job and a native PNG image clip. The PNG can be used as an Aftertake source, added to Film or downloaded. Recipe JSON contains editable parameters and hashes, not embedded image files: keep the original companion images alongside it and import those before restoring on another device. Restore verifies bytes, rebinds workspace IDs and does not render automatically.

Requests use `/api/layer-stacks`: `GET /` lists saved jobs, `GET /runtime` checks the CPU runtime, `POST /preview` returns the actual PNG, `POST /` creates or rejoins a job with `Idempotency-Key`, `GET /:id/recipe` exports a recipe, and `POST /resolve` restores a hash-bound recipe. A repeated accepted key returns its existing job; different settings with that key return a conflict. A server restart marks unfinished work interrupted and does not execute it again.

Scumble inspired the editable layer/mask workflow. Its implementation is GPL-3.0 and its Rust pixel crate is GPL-3.0-only; none of that code, GLSL, WASM, assets or test fixtures is included here. Aftertake's compositor was written independently using standard alpha-compositing and blend equations described by [W3C Compositing and Blending Level 1](https://www.w3.org/TR/compositing-1/).

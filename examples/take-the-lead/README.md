# TAKE THE LEAD

A 94-second narrated product film made with Aftertake's native editor and MCP.
One fashion shot becomes a new performance, a campaign design and a portrait
version. The closing shot shows the same opening playing inside the full
Aftertake project.

[Watch the film](https://github.com/ItsSNOWMOBILE/aftertake/releases/download/take-the-lead-review-2026-10-20/aftertake-take-the-lead.mp4)
· [Download the editable inputs](https://github.com/ItsSNOWMOBILE/aftertake/releases/download/take-the-lead-review-2026-10-20/aftertake-take-the-lead-inputs.zip)

## Follow the edit

| Time | What happens |
| :--- | :--- |
| 0–6 s | The completed campaign opens in landscape and portrait. |
| 6–20 s | The real source and character reference carry into the edit. |
| 20–30 s | The tracked person, source outfit and direction become a saved H3 take. The generation wait is explicitly omitted. |
| 30–38 s | The new replacement plays, followed by its actual result inside the app. |
| 38–59 s | The take becomes a subject design, a real title edit and kinetic typography. |
| 59–76 s | Separate voice and music tracks lead into campaign formats. |
| 76–94 s | Saved settings and workflow lead back to the real master project. |

## Open the project

Use the `aftertake-studio` branch and the ordinary Film setup in the main
[README](../../README.md). The input archive contains a master project, editable
scene projects, exact completed media, a media manifest, checksums and a plain
Node.js 24+ restore helper. Its own README gives the commands and manual import route.

Reassembling these completed inputs needs the CPU Film runtime. It starts no
model generation and spends no generation credits. Native scene projects retain
the individual shapes, pictures, typography, motion groups and audio settings
used to make the nested scenes.

The archive also includes the source video, fictional reference, prepared source,
tracking mask and character recipe for regenerating the H3 take. That separate
operation needs the installed local H3 profile and hardware preflight. It used
one primary reference with a focused head crop, source wardrobe and seed
`509019`. The accepted generation contains 119 frames at 24 fps. H3 adds a slight
smile and reconstructs some garment texture.

## What is recorded

Source/reference cards, enlarged direction controls, the pointer, waveforms and
workflow evidence are designed native animations using the actual job data.
The character-result view, title edit and closing master-project view are real
app recordings. The closing view was recorded before inserting that recording
into the project. Capture timing receipts distinguish their measured sampling
rates from the film's 24 fps delivery clock.

Narration uses the generic Michael preset in local Kokoro. The soundtrack and
sound effect are credited below, with their licenses preserved in the input pack.
